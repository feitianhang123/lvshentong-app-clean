# 绿色食品申报通 - 软件说明书

## 一、软件基本信息
- **软件名称**: 绿色食品申报通
- **版本号**: V1.0
- **软件类别**: 应用软件
- **开发语言**: HTML5 + CSS3 + JavaScript
- **运行环境**: Android WebView
- **开发完成日期**: 2026年4月

## 二、软件功能说明

### 2.1 主要功能模块

#### 模块一：产品目录
- **功能描述**: 提供绿色食品产品适用标准目录查询
- **核心功能**:
  - 标准目录浏览：显示完整的绿色食品产品适用标准
  - 产品搜索：支持按产品名称搜索标准
  - 目录查看：点击卡片查看详细标准内容
- **技术实现**: 基于Excel数据的JavaScript搜索算法

#### 模块二：现行标准
- **功能描述**: 提供绿色食品现行标准查询
- **核心功能**:
  - 标准分类浏览：产品标准和准则标准
  - 标准详情查看：显示标准名称、代码等信息
  - 下载功能：支持标准文件下载
- **技术特点**: 分类标签切换，响应式布局

#### 模块三：材料清单
- **功能描述**: 提供绿色食品申报材料清单
- **核心功能**:
  - 材料分类：6类申报材料展示
  - 详细说明：每类材料的详细要求和说明
  - 下载链接：相关表格和文档下载
- **交互设计**: 卡片式布局，点击展开详情

#### 模块四：预审核（待开发）
- **功能描述**: 绿色食品申报预审核功能
- **状态**: 待开发

## 四、安装和使用说明

### 4.1 安装方法
1. 通过GitHub Actions自动构建APK文件
2. 下载APK文件到Android设备
3. 安装并授权相关权限
4. 启动应用程序

### 4.2 使用说明
1. **主页面**: 选择需要使用的功能模块
2. **产品目录**: 搜索或浏览绿色食品标准
3. **现行标准**: 查询相关标准信息
4. **材料清单**: 查看申报所需材料
